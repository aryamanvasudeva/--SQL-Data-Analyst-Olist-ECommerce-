## Project Overview

This project demonstrates SQL skills by solving real-world business problems using the Olist Brazilian E-Commerce Dataset.

The analysis focuses on customer insights, sales performance, product analysis, logistics, and database optimization using SQL.

---

## Objective

- Analyze business data using SQL
- Practice real-world analytical queries
- Build a professional SQL portfolio project

## Business Questions Solved

1. Top states by number of customers
2. Top product categories by revenue
3. Highest priced products
4. Order count by status
5. Average product price
6. States having more than 500 customers
7. Products with highest freight charges
8. Product count by category
9. Create a reusable revenue view
10. Create an index to improve search performance
